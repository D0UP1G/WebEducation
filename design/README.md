# WebEducation — дизайн по брендбуку

Визуальный ориентир — [брендбук образовательной платформы, v1.1](../docs/assets/brandbook-educational-platform-v1.1.pdf). Для повторного использования токенов есть [brand-tokens.css](brand-tokens.css); он фиксирует палитру, шрифты, базовый шаг и плотность интерфейса для ученика и сотрудников.

Откройте [webeducation-prototype.html](webeducation-prototype.html) в браузере. Это самостоятельный интерактивный прототип, а не часть рабочего frontend. Переключатель показывает шесть согласованных экранов ученика, куратора и администратора. Вариантов палитры нет: цвета и светлая тема закреплены брендбуком. Все действия демонстрационные и не меняют реальные курсы.

В прототипе использованы примеры курса из брендбука и синтетические данные. Для ученика следующий шаг вынесен на первый план; ручная проверка предыдущей работы не блокирует прогресс. Статусы всегда обозначены иконкой и цветом, а сигналы о темпе видны только сотрудникам.

При дальнейшей реализации сохраняйте правила брендбука: Onest для интерфейса, JetBrains Mono только для кода и чисел; сетка от 4 px; светлая тема по умолчанию; акцентный синий — основной, янтарный — экономный акцент (не более 5% площади); студенческие тексты и основные действия крупнее плотных рабочих экранов. Не добавляйте градиенты карточкам и кнопкам, кроме предусмотренных брендбуком тёмных контекстов.
