# WebEducation — дизайн-прототип

Откройте [webeducation-prototype.html](webeducation-prototype.html) в браузере. Это самостоятельный интерактивный макет для сравнения направлений дизайна, а не часть рабочего frontend.

В верхней панели переключаются шесть экранов для ученика, куратора и администратора, четыре палитры и тёплый акцент палитры Signal. Начальный вариант — Signal / Абрикос. Вопрос ученика можно проверить, чтобы увидеть состояние принятого ответа и обновление прогресса.

Имена, работы и назначения — демонстрационные данные. Действия в макете не отправляют запросы к серверу и не меняют реальные курсы.
