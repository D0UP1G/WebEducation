Подтверждённые результаты и ограничения — в
[аудите соответствия](case-compliance-and-task-plan-2026-09-25.md).

Для новой задачи обновить `develop`, создать короткую ветку `feature/<task>`,
проверить изменение и его влияние на кейс, записать результат аудита, затем
открыть PR в `develop`. Полный контракт Python находится в
[API-контракте](api-contract.md); импорт можно проверить командой
`python manage.py import_curriculum --owner admin_demo --publish`, а локальные
демоданные создаются через `python manage.py seed_demo`. Результаты runner — в
[аудите Python](python-runner-audit-2026-09-25.md).
