# Единый план задач

Актуальная очередь P0 и её критерии готовности ведутся в
[аудите и плане от 25.09.2026](case-compliance-and-task-plan-2026-09-25.md).
Предыдущая версия этого файла распределяла работу между DEV-1/2/3/4 и
предполагала очередь Python. Команда перешла к одному агенту, а первая версия
изолированного runner выполняет проверку синхронно с общим бюджетом 45 секунд.
Старый план доступен в истории Git; его статусы не описывают текущую ветку.

Порядок до защиты: изолированный Python-runner и локальная самопроверка →
модули и импорт пакета 3/9/30 → Compose/Cloudflare Tunnel на стенде →
сквозной сценарий трёх ролей → релиз в `main`.

Для новой задачи обновить `develop`, создать короткую ветку `codex/<task>`,
проверить изменение и его влияние на кейс, записать результат аудита, затем
открыть PR в `develop`. Полный контракт Python находится в
[API-контракте](api-contract.md); проверки текущей ветки — в
[аудите runner](python-runner-audit-2026-09-25.md).
