## Что уже есть

Три роли, редактор и публикация версий, назначения, девять технических типов шагов, вопросы, ручная проверка с обязательными доказательствами и критериями куратора, прогресс, логи, CI, HTTPS Compose-профиль и скрипты резервирования. PR #41 и #44 адаптировали рабочий React к дизайну; PR #37 и #40 добавили карту, preflight и баллы; PR #45 добавил подсказку Scratch после неверной сдачи. В ветке `codex/python-server-runner` новая официальная Python-проверка проходит локальные тесты; Docker-стенд и публичный URL ещё не проверены. Исторические числа тестов относятся к прежнему срезу `develop`.
