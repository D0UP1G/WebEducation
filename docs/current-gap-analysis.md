# Сверка проекта после получения материалов организатора

Дата: 24 сентября 2026. База: develop на 618f8b0 после PR #27; эта документационная ветка добавляет исходные материалы и план, но не меняет код приложения. Источники: [кейс](../keys-obrazovatelnaya-platforma.pdf), [брендбук](organizer/brandbook.pdf), [учебный пакет](organizer/basic-curriculum.docx), [архитектура](../ARCHITECTURE.md), [роадмап](../ROADMAP.md), [API-контракт](api-contract.md), [реестр недостатков](mvp-deficiencies.md) и код. Назначения и критерии — в [текущем плане](team-work-plan.md).

## Что уже есть

Три роли, редактор и публикация версий, назначения, семь технических типов шагов, вопросы, ручная проверка, прогресс, логи, CI, HTTPS Compose-профиль и скрипты резервирования. На текущем develop локально прошли 43 backend-теста, 50 frontend-тестов, проверка миграций, TypeScript и production-сборка; GitHub CI на develop после PR #27 прошёл. Это не является приёмкой стенда.

## Приёмка до release

Нужны: импорт 3/9/30 без дублей и потери версий; проверка ролей и невыдачи ответов через API; официальный серверный прогон Python, на котором поддельный stdout не даёт баллы; брендбук в рабочем UI; HTTPS-стенд, восстановление БД и файлов, полный сценарий трёх ролей, зелёный CI и защита веток. До выполнения этих пунктов не объявлять MVP полностью принятым.
