## Что уже есть

Три роли, редактор и публикация версий, назначения, девять типов шагов, вопросы,
ручная проверка с обязательными доказательствами и критериями куратора, прогресс,
логи, CI, HTTPS Compose-профиль и backup/restore runbook работают. PR #50
добавил изолированный Python-runner и локальную самопроверку. PR #51 добавил
паспорт курса, ревизии модулей и повторяемый импорт материалов организатора;
локальные тесты и CI PR подтверждают 3 курса / 9 модулей / 30 шагов. Публичный
URL и полный E2E на всех ролях ещё не проверены.

API возвращает `modules` вместе с обратно совместимым плоским `steps`.
PR #52 отображает группы модулей в обзоре курса и боковой навигации ученика;
перед приёмкой остаётся проверить это на всех трёх
импортированных курсах.

На `feature/stepwise-python-editor` дополнительно реализуются последовательный
доступ к шагам (включая серверные запреты прямого чтения/отправки закрытых
шагов) и Python-редактор CodeMirror 6. Изменения и проверки этой ветки ещё не
влиты в `develop`; детали отражены в [пользовательских потоках](user-flows.md) и
[API-контракте](api-contract.md).

## Приёмка до release

Нужны: полный E2E на импортированных 3/9/30, проверка ролей и невыдачи ответов
через API, стендовый прогон Python runner с неверным/тайм-аутным и правильным
решением, проверка UI по брендбуку, HTTPS-стенд, восстановление БД и файлов,
зелёный CI и защита веток. До выполнения этих пунктов не объявлять MVP полностью
принятым.
