# Материалы организатора

В каталоге сохранены исходные материалы проекта:

| Файл | Назначение |
| --- | --- |
| [brandbook.pdf](brandbook.pdf) | Официальный брендбук образовательной платформы v1.1 |
| [basic-curriculum.docx](basic-curriculum.docx) | Учебный пакет: 3 курса, 9 модулей, 30 шагов |
| [curriculum-map.json](curriculum-map.json) | Машиночитаемая карта для импорта |

Оригинальные PDF и DOCX не редактируются. Их контрольные суммы сохранены в
карте и проверяются командой `preflight_curriculum_import`. Приложение при
запуске использует подготовленный JSON-манифест, а DOCX нужен для проверки
соответствия источнику.

## Подготовка и импорт

Из каталога `backend` выполните:

```bash
../.venv/bin/python manage.py preflight_curriculum_import
../.venv/bin/python manage.py import_curriculum --owner admin_demo --publish
```

Для демонстрационного стенда достаточно `../.venv/bin/python manage.py seed_demo`: команда
создаёт синтетические аккаунты, публикует официальный пакет и назначает курсы
ученику. Повторный запуск не создаёт дубликаты.

Подробные правила преобразования находятся в
[контракте импорта](import-contract.md), а соответствие исходных заданий типам
приложения — в [карте шагов](../organizer-step-map.md).

## Типы учебных шагов

| Исходный вид | Количество | `type_key` | Проверка |
| --- | ---: | --- | --- |
| Теория | 8 | `theory` | автоматическая после прочтения |
| Контрольный вопрос, один вариант | 5 | `quiz.single_choice` | автоматическая |
| Контрольный вопрос, несколько вариантов | 2 | `quiz.multiple_choice` | автоматическая |
| Контрольный вопрос с числом | 2 | `answer.exact` | автоматическая |
| Scratch с числовым ответом | 1 | `scratch.numeric_answer` | автоматическая |
| Ручная работа Scratch | 2 | `artifact.scratch` | куратор |
| Ручная работа Minecraft | 2 | `artifact.minecraft` | куратор |
| Проект | 2 | `artifact.project` | куратор |
| Python-задача по тестам | 6 | `algorithm.python` | изолированный runner |

Каждому шагу импортированного пакета назначен `max_score = 1`; суммы курсов
составляют 10, 8 и 12 баллов. Исходный пакет содержит ответы, критерии,
эталонные решения и тесты, поэтому опубликованный DOCX не следует считать
секретным. Ученический API всё равно скрывает закрытые ответы и критерии.

## Поля ручной сдачи

Карта задаёт обязательные доказательства:

- Scratch — `url`;
- Minecraft — `file` и `url`;
- проект — `file`, `url` и `explanation`.

Критерии куратора хранятся в `private_assessment.curator_criteria` и попадают в
закрытое `content.review_criteria`. Подсказка для неверного числового ответа
Scratch хранится отдельно и возвращается ученику только как feedback его
попытки.

## Брендбук

Брендбук является визуальным источником проекта. Рабочие цвета, шрифты,
отступы и статусы собраны в [design/brand-tokens.css](../../design/brand-tokens.css),
а правила применения описаны в [design/README.md](../../design/README.md).
