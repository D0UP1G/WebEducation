## Как повторить

В корне проекта выполните команды [README](../README.md#быстрый-запуск) для Docker Compose или локального запуска. После `seed_demo` откройте `http://localhost:8080/` для Compose либо `http://localhost:5173/` для Vite. Синтетические роли: `admin_demo`, `student_demo`, `curator_demo`; пароль у всех `demo`. По умолчанию создаётся один курс из шести шагов. Оригинальные три курса организатора (3/9/30) ещё не загружены в БД.

## Исправления интеграции

- Редактор теперь показывает добавление шага даже при автоматически открытом первом шаге и сохраняет поля импортера при изменении черновика. Добавлены поля обязательных доказательств, критериев куратора и подсказки Scratch.
- Ученик видит обязательные поля ручной сдачи; форма не отправляет неполный набор. Куратор видит закрытые критерии и раздельные комментарии ученика и проверки.
- Python-форма блокирует пустую отправку, очищает результат локальной самопроверки после сдачи и выводит число пройденных тестов и причину отказа понятным текстом.
- Исправлена форма слова для одной работы в очереди.

## Открытые ограничения

1. Официальная Python-сдача пока доверяет присланному браузером stdout и метрикам времени/памяти. Нужен изолированный серверный исполнитель DEV-1/DEV-3; текущий Python-контур годится для учебного показа, но не для защищённого зачёта.
2. Три курса пакета организатора ещё не импортированы. Сначала один агент добавляет модульную модель и паспорт, затем выполняет идемпотентный импорт и проверяет 30 шагов.
3. Публичный HTTPS-стенд и реальный Docker Compose остаются непроверенными. Нужно проверить их на машине с Docker, включая обновление прямых URL, загрузку Pyodide, скачивание файла, постоянные тома и восстановление резервной копии.
