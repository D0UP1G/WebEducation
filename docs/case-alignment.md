# Сверка с кейсом

Источники: [кейс хакатона](../keys-obrazovatelnaya-platforma.pdf) и
[пакет организатора](organizer/README.md). Актуальный подробный аудит,
статусы и очередь задач находятся в [плане от 25.09](case-compliance-and-task-plan-2026-09-25.md).
Описанный Python-runner реализован в `codex/python-server-runner` и до merge
не является частью `develop`.

Исходный DOCX содержит эталонные ответы и опубликован в публичном Git по
решению владельца. Его «скрытые» тесты не являются секретом. Серверный запуск
исключает подмену `stdout` из браузера, но для устойчивости к подгонке
понадобятся дополнительные тесты вне публичного пакета.

## Критерий приёмки

На HTTPS-стенде администратор импортирует, публикует и назначает три курса.
Ученик проходит теорию и вопросы, локально проверяет Python, получает
официальный результат серверного запуска и сдаёт Scratch/Minecraft с нужными
доказательствами. Куратор видит критерии, возвращает работу с обязательным
комментарием и принимает пересдачу. Прогресс отражает оба способа проверки,
а новая публикация не меняет старые назначения. Сохраняются БД и media после
перезапуска; CI и релизный PR в `main` проходят.
