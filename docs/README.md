# Документация WebEducation

Документы описывают запуск, устройство и пользовательское поведение текущего
проекта. Главный вход для нового пользователя — корневой [README](../README.md).

## Основные документы

1. [Архитектура](../ARCHITECTURE.md) — компоненты, роли, данные и границы
   системы.
2. [API-контракт](api-contract.md) — маршруты, форматы запросов, статусы и
   правила доступа.
3. [Пользовательские сценарии](user-flows.md) — страницы ученика, куратора и
   администратора.
4. [Сверка с кейсом](case-alignment.md) — обязательные возможности, границы
   MVP и сценарий демонстрации.
5. [Roadmap](../ROADMAP.md) — реализованные возможности и следующий этап.

## Запуск и данные

- [Развёртывание](deployment.md) — Docker Compose, локальная разработка, LAN,
  HTTPS, конфигурация и диагностика.
- [База данных](database.md) — миграции, импорт учебного пакета, демо-данные,
  резервное копирование и восстановление.
- [Устранение неполадок](troubleshooting.md) — типовые проблемы запуска и
  проверки.

## Учебный пакет и дизайн

- [Материалы организатора](organizer/README.md) — брендбук, исходный учебный
  пакет и карта импорта.
- [Карта шагов](organizer-step-map.md) — соответствие исходных заданий типам
  приложения.
- [Контракт импорта](organizer/import-contract.md) — правила преобразования
  карты в курсы и шаги.
- [Дизайн и брендбук](../design/README.md) — токены, прототип и визуальные
  ограничения.

Исходные PDF, DOCX и JSON в `docs/organizer/` сохранены как материалы проекта.
Изменять учебный DOCX и брендбук не следует; изменения содержания вносятся в
машиночитаемую карту и проверяются импортом.
