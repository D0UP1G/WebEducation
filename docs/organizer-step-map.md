# Карта шагов пакета организатора

Источник: [оригинальный пакет](organizer/basic-curriculum.docx). Это карта
соответствия для импорта; исходный DOCX остаётся неизменным. `type_key`
определяет способ сдачи и проверки, а исходное название шага и педагогический
контекст сохраняются в курсе. Режимы: `instant` — серверная проверка ответа
(для Python — отдельный изолированный runner), `manual` — решение куратора.
Локальный браузерный запуск Python служит только самопроверкой.

Итого: Scratch — 10 шагов, Minecraft Education — 8, Python — 12; всего 3
курса, 9 модулей и 30 шагов. Все девять `type_key` поддерживаются текущим
приложением. Каждый курс содержит теорию и контрольный вопрос. Подробные
правила записи содержания находятся в [контракте импорта](organizer/import-contract.md).

Машиночитаемая карта использует `scratch.numeric_answer` для шага 1.1.3; для
ручных шагов задаются обязательные поля `file`, `url` и `explanation`, а
исходные названия сохраняются в `evidence_fields`.

Правильные ответы и критерии хранятся на сервере и не выходят через ученический
API. Оригинал DOCX доступен в репозитории, поэтому его помеченные тесты не
следует считать секретными. Карта хранит `private_assessment.curator_criteria`
списком, а импортёр объединяет их в `content.review_criteria` с сохранением
порядка.
