# Frontend WebEducation

React + TypeScript клиент трёх ролей. Сейчас используются базовые рабочие
элементы без окончательной дизайн-системы. Все API-запросы идут на `/api/v1/`
с сессионными cookies и CSRF-токеном.

## Локальный запуск

Сначала запустите Django на `http://localhost:8000` и выполните `seed_demo`
по корневому README, включая переменную `DJANGO_CSRF_TRUSTED_ORIGINS` для
локального входа. Затем:

```bash
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:5173/`. Демо-логины: `admin_demo`,
`student_demo`, `curator_demo`; пароль `demo`.

## Проверка

```bash
npm run typecheck
npm test
npm run build
```

Production build собирается при `docker compose up --build`; nginx отдаёт
файлы React по `/`, включая кабинет администратора `/admin/`, а API проксируется по `/api/`.
Django admin доступен только при прямом локальном запуске backend на порту 8000.

## Текущее подключение

- Работают с текущим backend: auth, каталог/шаги/прогресс ученика, редактор
  курсов, предпросмотр, публикация и назначения администратора.
- UI сдач, вопросов и куратора подключён к реализованным маршрутам DEV-3.
  Текущий Python запускается в браузере через Pyodide; сервер сравнивает
  присланные результаты и потому не может считать их защищённым зачётом.
- После получения материалов организатора нужно подключить официальный
  брендбук, модули и все 30 шагов; официальный Python-зачёт должен повторно
  запускать исходный код в изоляции на сервере. Текущие задачи — в
  [плане команды](../docs/team-work-plan.md).
