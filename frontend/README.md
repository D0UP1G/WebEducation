# Frontend WebEducation

Frontend — React + TypeScript-клиент для ученика, куратора и администратора.
Все запросы идут на `/api/v1/` с сессионными cookies и CSRF-токеном. Рабочие
стили используют токены из [`design/brand-tokens.css`](../design/brand-tokens.css)
и правила брендбука v1.1.

## Локальный запуск

Запустите Django на `http://localhost:8000`, примените миграции и выполните
`seed_demo` по [корневому README](../README.md). Затем:

```bash
cd frontend
npm ci
npm run dev
```

Откройте <http://localhost:5173/>. Демо-логины: `admin_demo`, `student_demo`,
`curator_demo`; пароль — `demo`.

## Проверка

```bash
npm run typecheck
npm test
npm run build
```

Скрипты `dev` и `build` автоматически подготавливают Pyodide из установленного
пакета. CDN для локальной самопроверки Python не требуется.

## Реализованные области

- вход, выход и ролевые маршруты;
- каталог курсов, модули, шаги, прогресс и попытки ученика;
- Markdown-теория и CodeMirror-редактор Python;
- очередь и форма ручной проверки, вопросы и защищённые вложения куратора;
- редактор курсов, предпросмотр, публикация, пользователи и назначения
  администратора;
- состояния загрузки, ошибки, пустые списки и адаптивные экраны.

Локальная проверка Python предназначена только для открытого примера и не
начисляет баллы. Кнопка отправки передаёт код backend, а официальный результат
возвращается из изолированного runner.
